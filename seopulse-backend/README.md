# SEOPulse

SEOPulse is a production-ready website SEO audit platform built with Spring Boot and PostgreSQL.

## Features

- Website SEO auditing
- Technical SEO analysis
- Meta tag analysis
- Heading analysis
- Link analysis
- Performance-related checks
- SEO score calculation
- Audit history
- User authentication
- REST APIs
- API documentation
- Docker support
- Production deployment

## Tech Stack

### Backend
- Java
- Spring Boot
- Spring Security
- Spring Data JPA
- Hibernate
- PostgreSQL
- Redis
- Maven

### DevOps
- Docker
- Docker Compose
- Git
- GitHub
